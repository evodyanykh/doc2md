# doc2md — конвертер документов в Markdown

**doc2md** — программа для преобразования документов Word, PDF и PowerPoint в формат Markdown.  
Она автоматически извлекает текст и сохраняет структуру документа: заголовки, списки, таблицы, ссылки и другое форматирование.  
Если PDF состоит из сканированных страниц, программа может распознать текст с помощью встроенного OCR.

---

## Подойдёт, если вы

- работаете с документацией и хотите перевести её в Markdown;
- ведёте базу знаний в Obsidian, Notion или любом другом инструменте, поддерживающем Markdown;
- переносите старые документы в современный формат;
- публикуете статьи или техническую документацию в Markdown;
- хотите быстро обработать большое количество файлов за один раз.

---

## Возможности

- ✅ **Word (.docx)** → Markdown
- ✅ **PDF** → Markdown
- ✅ **PowerPoint (.pptx)** → Markdown
- ✅ **OCR для сканов** (распознавание текста на изображениях внутри PDF)
- ✅ **Одновременная обработка нескольких файлов**
- ✅ **Веб-интерфейс** на основе Streamlit
- ✅ **Командная строка** (CLI) для автоматизации
- ✅ **Автоматическое сохранение результатов** в папку с исходниками или в выбранную директорию

---

## Как это работает

```
Документ (DOCX, PDF, PPTX)
         │
         ▼
      doc2md
         │
         ▼
Markdown (.md)
```

Программа анализирует структуру документа, преобразует форматирование в эквивалентные элементы Markdown и сохраняет результат в виде отдельного файла.

## Быстрый старт

### Шаг 1. Установите Python

Скачайте и установите Python версии **3.8 или выше** с [официального сайта](https://www.python.org/downloads/).

### Шаг 2. Скачайте проект

Клонируйте репозиторий или скачайте ZIP-архив:

```bash
git clone https://github.com/ваш-username/doc2md.git
cd doc2md
```

### Шаг 3. Откройте терминал

Перейдите в папку с проектом через терминал (командную строку).

### Шаг 4. Установите зависимости

```bash
pip install -r requirements.txt
```

### Шаг 5. Запустите программу

Для веб-интерфейса выполните:

```bash
streamlit run app.py
```

После запуска автоматически откроется браузер с интерфейсом программы.

## Как пользоваться

### Конвертация одного документа

1. Запустите программу (см. Шаг 5).
2. В открывшемся окне браузера перетащите файл в область загрузки или выберите его через кнопку «Обзор».
3. Нажмите кнопку **Конвертировать**.
4. Дождитесь завершения обработки (прогресс отображается на экране).
5. Скачайте готовый Markdown-файл — он будет предложен автоматически.

### Если файлов несколько

- Вы можете выбрать несколько файлов одновременно (зажать Ctrl или Shift при выборе).
- Программа обработает их по очереди, и вы сможете скачать каждый результат отдельно или все сразу в ZIP-архиве.

### Если документ — скан (PDF с картинками)

- Убедитесь, что в настройках включена опция **«Использовать OCR»**.
- Программа автоматически запустит распознавание текста (может занять дополнительное время).
- Результат будет содержать распознанный текст, вставленный в Markdown.

## OCR (распознавание текста)

Функция OCR подключается автоматически, если выбран соответствующий флажок в интерфейсе.  
Для работы требуется **Tesseract OCR**, установленный в системе:

- **Windows**: скачайте установщик с [GitHub](https://github.com/UB-Mannheim/tesseract/wiki) и добавьте в PATH.
- **macOS**: `brew install tesseract`
- **Linux**: `sudo apt install tesseract-ocr`

Без Tesseract OCR программа будет работать только с текстовыми PDF.

## Частые вопросы

**Не открывается браузер после запуска**  
Проверьте, не блокирует ли файрвол или антивирус порт, на котором запускается Streamlit (по умолчанию 8501). Можно вручную открыть в браузере адрес `http://localhost:8501`.

**Не запускается программа**  
Убедитесь, что установлены все зависимости из `requirements.txt`. Если ошибка связана с отсутствием модуля, попробуйте обновить pip: `pip install --upgrade pip`.

**Почему PDF распознался не полностью?**  
Если PDF содержит сложные таблицы или колонтитулы, часть форматирования может потеряться. В таких случаях рекомендуется предварительно преобразовать PDF в DOCX с помощью сторонних инструментов.

**Почему OCR не работает?**  
Проверьте, установлен ли Tesseract и добавлен ли в PATH. Также убедитесь, что в интерфейсе включена опция OCR. Если PDF уже содержит текстовый слой, OCR не требуется.

## Для опытных пользователей

### Использование в командной строке (CLI)

```bash
python cli.py --input document.docx --output result.md --ocr
```

Доступные аргументы:
- `--input` — путь к файлу или папке с файлами.
- `--output` — папка для сохранения результатов (по умолчанию рядом с исходником).
- `--ocr` — включить OCR для PDF.
- `--recursive` — обрабатывать файлы в подпапках.

### Использование как библиотеки

```python
from doc2md import convert

markdown_text = convert('document.docx', ocr=False)
print(markdown_text)
```

### Модули

- **docx_parser** — извлекает текст и форматирование из DOCX.
- **pdf_parser** — обрабатывает текстовые PDF, при необходимости вызывает OCR.
- **pptx_parser** — преобразует слайды PowerPoint в заголовки и маркированные списки.
- **ocr** — обёртка над Tesseract для распознавания текста на изображениях.
